# local_code_worker (веб-интерфейс)

Веб-обертка над локальным ИИ-агентом переработки кода. Рассчитана на одного
пользователя, аутентификация не требуется.

## Что делает

1. Скачивает ZIP-архив репозитория по указанному URL.
2. Извлекает все `.py` файлы и отправляет их локальной модели
   (`qwen25-coder-14b-unc` или другой, OpenAI-совместимый API).
3. Модель вносит изменения по вашему промпту и возвращает их в виде JSON.
4. Правки применяются к файлам, собирается новый ZIP-архив.
5. Архив доступен для скачивания в браузере (также хранится последние 20
   штук на сервере в папке `results/`).

## Запуск
pyth  
```bash
pip install -r requirements.txt
python app.py
```

Открыть в браузере: http://localhost:5000

## Интерфейс

- **URL ИИ API** — адрес локального сервера модели (по умолчанию `http://192.168.0.23:8000/`).
- **URL архива** — ссылка на `.zip` репозитория для переработки.
- **Модель** — имя модели на сервере.
- **Пароль API** — значение заголовка `X-API-Password`, который добавляется
  ко всем запросам к ИИ API.
- **Промпт** — задача для модели (например: «добавь ко всем методам докстринги»).

После обработки появляется кнопка **Скачать архив**, а журнал работы
отображается прямо на странице.

## Структура проекта

```
app.py                  # Flask-приложение (маршруты, API, отдача архивов)
modules/
  ai_worker.py          # Клиент ИИ API (заголовок X-API-Password, запуск модели)
  rework_worker.py      # Ядро: скачивание, безопасная распаковка, применение правок
params/
  settings.py           # Логгер, промпты, значения по умолчанию
templates/index.html    # Веб-интерфейс
static/                 # CSS и JS
tests/test_e2e.py       # Сквозной тест с мок-сервером ИИ (pytest)
```

## Тесты

```bash
python -m pytest tests/ -v
```

Тест поднимает мок-сервер ИИ API и мок-архив, прогоняет весь цикл
«запрос → переработка → скачивание» без реальной модели.
